## MakerBuilder

Both a NPM package, at `@openworkshop/maker-builder`, and a Docker container.

In effect, this provides all CI services for containerized builds and runs.
The Dockerfile is meant to be deployed to Buildkite agents.
Thus, much of this repository has to do with BTD (building, testing, and deploying) of the software.
